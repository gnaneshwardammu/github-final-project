
# Simple Interest Calculator

A simple Bash script that calculates simple interest based on the principal amount, annual rate of interest, and time period entered by the user.

## Description

This project demonstrates how to use a Bash script to calculate simple interest using the formula:

Simple Interest = (Principal × Rate × Time) / 100

## Inputs
- Principal amount
- Annual rate of interest (percentage)
- Time period (in years)

## How to Run

1. Clone or download this repository.
2. Open a terminal in the project directory.
3. Make the script executable:

   chmod +x simple-interest.sh

4. Run the script:

   ./simple-interest.sh

## Example

Enter the principal: 1000
Enter the annual rate of interest: 5
Enter the time period (in years): 2

Simple Interest = 100.00

- Bash
